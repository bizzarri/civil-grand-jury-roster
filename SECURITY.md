# Security reporting

Do not post real juror information, private handoffs, credentials or exploit details involving live data in public issues.

If GitHub's **Report a vulnerability** option is available in this repository's Security tab, use it. Otherwise, open a minimal public issue requesting a private reporting channel without disclosing the vulnerability or sensitive data. Wait for a maintainer to arrange that channel.

Only the current development baseline is maintained at this stage. There is no guaranteed support response time and no independent security certification. See docs/PRIVACY.md for the current protection model and limits.
